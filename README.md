# אנגלית עם נועה

אפליקציית Web (PWA) ללימוד אנגלית לקראת המבחן של כיתה ג׳: אותיות A–P, מספרים 1–20, עשרה צבעים ושבע מילים.
React + TypeScript + Vite. אין שרת, אין הרשמה, ההתקדמות נשמרת במכשיר.

## רשימת התוכן הסגורה (המקור היחיד לתוכן)

| תחום | תוכן | קובץ |
|---|---|---|
| אותיות | A–P: שם, צליל פונטי בסיסי, אות גדולה/קטנה, כתיבה | `src/content/letters.ts` |
| מספרים | 1–20, דגש על שמיעה (13↔3, 14↔4) | `src/content/numbers.ts` |
| צבעים | green, yellow, blue, purple, pink, gray, white, black, brown, orange | `src/content/colors.ts` |
| מילים | cat, dog, banana, tap, ball, bag, hat | `src/content/words.ts` |

המילים לדוגמה של האותיות (apple, egg, igloo…) מוצגות עם תמונה ושמע בלבד – לא נדרשת קריאה שלהן, והן לא מופיעות במבחן כמילים לקריאה.

## מבנה

- `src/content/` – תוכן לימודי בלבד.
- `src/audio/` – מנגנון השמע (`player.ts`), קטלוג כל הקליפים (`clips.ts`), הקלטות הורים (`recordings.ts`), דוחות הבדיקה (`*-audit.json`).
- `src/learn/` – מודל השאלות והמשחקים (`questions.ts`), מסלול 6 המפגשים (`path.ts`), התקדמות ושליטה (`progress.ts`).
- `src/ui/`, `src/screens/`, `src/art/` – ממשק, מסכים ואיורים.
- `public/audio/` – קובצי השמע (רגיל + `slow/` + `phonemes/`).

## שמע

- **שמות אותיות, מספרים, צבעים, מילים והוראות**: הוקלטו מראש בקול נוירוני en-US (Jenny), כל קליפ במהירות רגילה ובמהירות איטית (הקלטה איטית אמיתית, לא מתיחה). 251 קליפים × 2.
- **צלילים פונטיים** (`public/audio/phonemes/*.wav`): קבצים נפרדים לגמרי משמות האותיות. כל צליל נחתך אוטומטית מתוך מילה אמיתית מוקלטת (למשל /b/ מתוך bat, /æ/ מתוך at, /m/ מתוך am) בלי תוספת "אה". צלילים ארוכים (m, n, l, f) מוחזקים כ־0.3 שנ׳.
- **הקלטה עצמית**: באזור ההורים → "בדיקת צלילים" אפשר להקליט כל צליל בקול (2 שניות). ההקלטה נשמרת במכשיר ומחליפה את הקובץ.
- אין שימוש בהקראת תו בודד ע״י מנוע דיבור. אם קובץ צליל חסר – מוצגת הודעה ולא משמיעים תחליף.

### הוספה או החלפה של קליפ

1. להוסיף טקסט ב־`src/audio/clips.ts` (או תוכן חדש ב־`src/content`).
2. `npm run audio:make` – מקליט רק מה שחסר, מקצר שקט, ובונה מחדש את הצלילים.
3. `npm run audio:verify` – בדיקת זיהוי דיבור לכל הקבצים.

כדי להחליף קובץ בהקלטה מקצועית: לשמור אותו באותו שם בדיוק (`public/audio/<id>.mp3`, `public/audio/phonemes/<letter>.wav`).

```bash
npm install
npm run dev
npm run build
```
