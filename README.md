# Noa's English World

**עולם האנגלית של נועה, לומדים ונהנים ביחד!**

אפליקציית Web (PWA) ללימוד אנגלית לכיתה ג׳, לקראת המבחן: אותיות A–P, מספרים 1–20, עשרה צבעים ושבע מילים.
האפליקציה נוצרה במקור עבור נועה, ומתאימה לכל הבנים והבנות בכיתה: כל ילד וילדה נכנסים עם שם פרטי או כינוי ומקבלים פרופיל אישי.

- בלי הרשמה, סיסמה, מייל או טלפון. ההתקדמות נשמרת רק במכשיר.
- עובדת בדפדפן (Chrome, Safari, Samsung Internet) בטלפון, בטאבלט ובמחשב, ואפשר להתקין אותה למסך הבית.
- אחרי פתיחה ראשונה עם אינטרנט היא עובדת גם בלי אינטרנט, כולל כל קובצי השמע.

React 19 · TypeScript · Vite · ללא שרת וללא בסיס נתונים.

---

## הרצה מקומית

דרוש Node.js 20 ומעלה.

```bash
npm install
npm run dev        # http://localhost:5290
npm test           # בדיקות איכות (Vitest)
npm run build      # בניית Production לתיקייה dist
npm run preview    # הרצת גרסת ה-Production מקומית: http://localhost:5291
```

## הוספת תוכן

- **טקסט בממשק** – רק ב־`src/text/he.ts`. לשמור על עברית טבעית שמתאימה לכולם: "מקשיבים ובוחרים", "מה התשובה?", "עוד ניסיון קטן!", בלי "בחר/י". הבדיקה `npm test` נכשלת אם מופיע ניסוח בלשון נקבה בלבד או לוכסן.
- **מילה, צבע או אות חדשים** – בקובץ המתאים ב־`src/content/`. השאלות, המשחקים והמבחן נבנים מהתוכן אוטומטית. (שימו לב: המבחן מכוון לחומר הרשמי, והבדיקות מוודאות שאין בו תוכן מחוץ לרשימה.)
- **קליפ שמע חדש** – להוסיף את הטקסט האנגלי ב־`src/audio/clips.ts`, ואז:

```bash
npm run audio:make     # מקליט רק מה שחסר (רגיל + איטי), מקצר שקט, בונה צלילים פונטיים
npm run audio:verify   # בדיקת זיהוי דיבור לכל הקבצים (Windows)
```

- **החלפה בהקלטה מקצועית** – לשמור קובץ באותו שם בדיוק (`public/audio/<id>.mp3`, `public/audio/slow/<id>.mp3`, `public/audio/phonemes/<אות>.wav`).

## שמע

- שמות אותיות, מספרים, צבעים, מילים והוראות: הוקלטו מראש בקול נוירוני en-US, במהירות רגילה ובמהירות איטית אמיתית.
- צלילים פונטיים: קבצים נפרדים משמות האותיות. כל צליל נחתך ממילה אמיתית (למשל /b/ מתוך bat) בלי "אה" אחרי העיצור. באזור ההורים ← "בדיקת צלילים" אפשר לאשר כל צליל או להקליט אותו מחדש במכשיר.
- אין שימוש בהקראת תו בודד. אם קובץ צליל חסר, מוצגת הודעה במקום תחליף.

## פרופילים ופרטיות

כל פרופיל = שם פרטי או כינוי בלבד. ההתקדמות נשמרת ב־localStorage של הדפדפן, בנפרד לכל פרופיל (`noa-english:p:<id>:save`). האפליקציה מבקשת מהדפדפן שמירה קבועה (`navigator.storage.persist`). אין סנכרון בין מכשירים ואין שרת – מי שמשתמש באותו מכשיר יכול לפתוח כל פרופיל.

## פרסום ועדכונים

האתר: **https://fortestudio26.github.io/noas-english-world/**

הקוד נמצא ב-GitHub, והאתר מתפרסם ב-GitHub Pages דרך `.github/workflows/pages.yml`. כל `git push` לענף `main` מריץ בדיקות, בונה ומפרסם גרסה חדשה תוך כ-2 דקות (אם בדיקה נכשלת – לא מתפרסם כלום).
באפליקציה המותקנת מופיעה הודעה "יש גרסה חדשה" – העדכון מתבצע רק בלחיצה, כדי לא לשבור שיעור באמצע. ההקלטות וההתקדמות נשמרות.

לפני כל פרסום:

```bash
npx tsc -b && npm test && npm run build
```
